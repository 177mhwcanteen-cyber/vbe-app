# VBE खरीद-हिसाब — App

Vande Bharat Enterprises का खरीद-हिसाब dashboard।

**App यहाँ खुलता है:** https://177mhwcanteen-cyber.github.io/vbe-app/

- 📊 Overview — महीने का खर्च, बकाया, charts
- ➕ नई एंट्री — हाथ से खर्चा जोड़ें
- 🧾 बिल — सारे बिल, filter + खोज
- 💹 Pricebook — किस चीज़ का क्या रेट चल रहा है
- ⚠️ Flags — जिन बिलों पर ध्यान चाहिए
- 🏦 मिलान — बैंक/PhonePe statement डालो, पैसा अपने-आप बिलों से मिल जाए

सिर्फ़ यही एक पन्ना यहाँ रहता है। पूरा डेटा Firestore में है और
Google sign-in + UID whitelist + security rules से सुरक्षित है।
Bot का code और बाकी सब private repo में है।
